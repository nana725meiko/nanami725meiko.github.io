# Mini CD Charm 試作デモ(NFC音楽プレーヤー)

NFCタグにタップすると開く、音楽の再生ページです。

## 入っているもの
- `index.html` … 再生ページ(これ1枚で動きます)
- `audio/track1.mp3`, `audio/track2.mp3` … デモ用に作成した曲(自由に差し替えできます)
- `cover.jpg` … ジャケット画像(仮)

## GitHub Pagesで公開する手順
1. GitHubで、新しいリポジトリを作ります(**Public**を選びます)。
2. このフォルダの中身を、**フォルダごと**ではなく**中のファイルを**そのままアップロードします。
   - `index.html`、`cover.jpg`、`audio` フォルダが、リポジトリの一番上に並ぶ形にします。
3. Settings → Pages → 「Deploy from a branch」→ ブランチは `main`、フォルダは `/ (root)` → Save。
4. 数分待つと、`https://アカウント名.github.io/リポジトリ名/` で公開されます。
5. **スマホ(iPhoneとAndroid)で、そのURLを開いて、再生できるか確認します。**
6. NFCタグに、そのURLを書き込みます(例:無料アプリ「NFC Tools」→ 書き込み → レコードを追加 → URL)。
7. 動作を確認したら、タグにロックをかけます(配布中の上書きを防ぎます)。

## 曲を差し替えるとき
1. `audio` フォルダに、MP3を入れます(目安:1曲 128kbps で約4MB)。
2. `index.html` の中の、`TRACKS` の部分(「曲の設定」と書いてある所)を書き換えます。
   ```js
   const ALBUM = { artist: "アーティスト名", cover: "cover.jpg" };
   const TRACKS = [
     { title: "曲名1", file: "audio/song1.mp3" },
     { title: "曲名2", file: "audio/song2.mp3" }
   ];
   ```
3. ページ下部の「音源:…」のクレジット表記も、書き換えてください。
4. `cover.jpg` を、本物のジャケット画像(正方形)に差し替えます。

## 注意
- **公開リポジトリの中身は、誰でもダウンロードできます。** 権利者の許可がない音源や、限定音源は置かないでください。
- フリー音源は、**ファイルの再配布(公開サイトに置くこと)と商用利用が許されているか**を、規約で確認してください。
- 音の自動再生はできません(スマホの仕様)。画面のディスクか再生ボタンをタップして再生します。
- GitHub Pagesの利用上限(サイトは1GB以下、月の通信量はゆるやかに100GB)を超えないようにしてください。
- 長く配る場合は、タグに自社ドメインのURLを書き込み、そこからこのページへ転送する形にすると、置き場所を変えても、配ったタグが使えます。
